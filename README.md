# Pakistani Social Media Content Detective

A data analytics project that explores social media engagement across platforms.

## Project Objectives
- Compare engagement across platforms.
- Analyze content types.
- Explore hashtags and popular topics.
- Study sentiment and engagement.
- Identify potential posting-time patterns.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## How to Run
Install the requirements:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```

## Dataset
The included dataset is a small synthetic sample created for demonstration and testing. It does not represent actual Pakistani social media activity.
